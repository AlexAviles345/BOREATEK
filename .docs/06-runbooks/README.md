# 06 — Runbooks y Procedimientos Operativos (`06-runbooks`)

Esta carpeta contiene guías operativas paso a paso para ejecutar tareas recurrentes de desarrollo, integración de arte 3D, configuración de iluminación URP y empaquetado de builds en **Unity 6 (`6000.6.0f1`)**.

## 📄 Runbooks Disponibles

* [**`git-workflow-and-unity-merge.md`**](git-workflow-and-unity-merge.md) — Flujo de ramas Git (`main`, `develop`, `feature/*`), convención de commits y reglas para prevenir conflictos en escenas `.unity`, `.prefab` y archivos `.meta`.
* [**`create-new-biome-and-node.md`**](create-new-biome-and-node.md) — Procedimiento paso a paso para importar un modelo 3D estilizado, crear su material URP, su `ScriptableObject` y su Prefab interactivo.
* [**`urp-lighting-and-fog-setup.md`**](urp-lighting-and-fog-setup.md) — Configuración exacta del `Global Volume` (*Bloom*, *Vignette*), luces de guirnaldas sin sombras y niebla de **Ventisca Ciega**.
* [**`build-and-release-pipeline.md`**](build-and-release-pipeline.md) — Proceso de compilación en Unity 6, verificación pre-entrega y empaquetado para la Mini Game Jam.
