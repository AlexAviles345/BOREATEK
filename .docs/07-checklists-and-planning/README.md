# 07 — Planificación, Roadmap y Checklists (`07-checklists-and-planning`)

Esta carpeta organiza la planificación de desarrollo de **BOREATEK**, el cronograma por hitos y las listas de verificación independientes para programación, arte 3D estilizado y control de calidad (QA).

## 📄 Documentos de esta Sección

* [**`roadmap-and-milestones.md`**](roadmap-and-milestones.md) — Plan de implementación en 5 fases desde la inicialización en Unity 6 hasta el clímax de *La Gran Nochebuena*.
* [**`core-systems-checklist.md`**](core-systems-checklist.md) — Checklist técnico para los módulos C# (`PlayerController`, `TemperatureSystem`, `HarvestableNode`, `InventoryAndShop`, `DayNightCycleManager`, `DefectiveToyAI` y `Automation`).
* [**`art-3d-and-audio-checklist.md`**](art-3d-and-audio-checklist.md) — Checklist de producción de modelos 3D *low-poly* estilizados, materiales URP, shaders, iluminación y audio.
* [**`qa-performance-and-release-checklist.md`**](qa-performance-and-release-checklist.md) — Checklist de validación jugable, rendimiento a `60+ FPS` y empaquetado para la Mini Game Jam.
