# 02 — Biblia de Arte y Dirección Visual (Art Bible)

Esta carpeta define las directrices visuales obligatorias de **BOREATEK**, la relación entre el arte conceptual y el acabado final en **Unity 6 (URP)**, las especificaciones de modelado 3D estilizado, la paleta cromática y aloja la galería oficial de **Concept Art**.

## 📄 Documentos y Recursos de esta Sección

* [**`visual-direction-lowpoly-vs-concept.md`**](visual-direction-lowpoly-vs-concept.md) — **Aclaración Crítica Obligatoria:** Por qué el juego final es **3D Animado, Estilizado / *Low-Poly* Texturizado** y cómo interpretar correctamente las imágenes conceptuales.
* [**`color-palette-and-urp-lighting.md`**](color-palette-and-urp-lighting.md) — Contraste cromático entre el Frío Ártico y el Calor Industrial/Neón, códigos hexadecimales, configuración de luces, niebla exponencial y `Global Volume` en URP.
* [**`3d-modeling-and-character-standards.md`**](3d-modeling-and-character-standards.md) — Proporciones caricaturescas/*chibi*, presupuesto de triángulos, resolución de texturas, escala modular en metros y pivotes para Unity.
* [**`shaders-and-vfx-specs.md`**](shaders-and-vfx-specs.md) — Especificación de materiales PBR estilizados, shaders en Shader Graph (Hielo Translúcido, Cristal Emisivo, Nieve) y sistemas de partículas (Ventisca Ciega, Chispas, Calor).
* [**`concept-art/`**](concept-art/) — Galería con las 11 piezas de arte conceptual divididas en [`paisajes/`](concept-art/paisajes/) (9 biomas/clima) y [`personajes/`](concept-art/personajes/) (2 entidades).
