# 08 — Prompts Estandarizados y Plantillas (`08-prompts-and-templates`)

Esta carpeta almacena los prompts oficiales para generación de referencias visuales y asistencia de código C# en Unity 6, así como las plantillas Markdown para mantener uniforme el crecimiento de la documentación.

## 📄 Documentos y Plantillas

* [**`ai-art-and-3d-prompts.md`**](ai-art-and-3d-prompts.md) — Prompts calibrados para generar arte conceptual, hojas de diseño de personajes (*turnarounds* 3D estilizados/*chibi*) y referencias de modelos *low-poly*.
* [**`unity-csharp-coding-prompts.md`**](unity-csharp-coding-prompts.md) — Prompts de sistema para programar o auditar scripts C# bajo la arquitectura de **BOREATEK**.
* [**`templates/`**](templates/) — Plantillas listas para copiar:
  * [`biome-spec-template.md`](templates/biome-spec-template.md) — Plantilla para documentar nuevos biomas o estratos.
  * [`csharp-module-spec-template.md`](templates/csharp-module-spec-template.md) — Plantilla para documentar nuevos scripts/módulos C#.
  * [`adr-template.md`](templates/adr-template.md) — Plantilla para nuevos Architecture Decision Records.
